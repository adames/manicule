make it yours

the hosted page ranks my feeds. for yours:

forking needs a github account. no account? the feed page is already yours: pick what you'd read and keep the link, it holds your marks. a fork is for people who want their own list of feeds on a page like this one. three ways, pick your channel

in the terminalneeds gh

gh repo fork adames/manicule --clone && cd manicule
cp ~/path/to/your/feeds.opml feeds.opml
git commit -am "my feeds" && git push
gh api -X POST repos/{owner}/{repo}/pages \
  -f build_type=workflow
gh workflow run corpus

five lines: fork and clone, swap the feed list, push, turn on pages, build. a few minutes later your page is up

your siterefreshed once a day

in the browserfork on github

no terminal, no code. you need a free github account and a list of your feeds. any feed reader exports that list as one file, usually called feeds.opml or subscriptions.opml. youtube channels, podcasts, and blogs all work

  1. press fork and accept. github makes you a copy of this project
  2. in your copy, open the file feeds.opml, press the pencil to edit, paste your own file's contents over it, and press commit changes
  3. open settings, then pages in the left column. under source, choose github actions
  4. open the actions tab, choose corpus on the left, press run workflow. this builds the page; it takes a few minutes

your page is at https://<you>.github.io/manicule/ with your github name in place of <you>. it refreshes itself every morning

your marks stay in your browser and your links

no website, a filemanicule.py

the ranker without a page. one python file reads your feeds, ranks them by a folder of notes you already keep, and writes a markdown file

uv sync
uv run manicule.py rank feeds.opml \
  --picked ~/notes \
  -o today.md

--picked is any folder of .md/.txt. an obsidian folder, saved articles, whatever you have. point it at notes you already keep, not a folder you maintain for this

put it on a cron and read today.md with coffee

cron
17 6 * * * uv run manicule.py rank feeds.opml --picked ~/notes -o today.md
