# labels.txt — what a taste can be about.
#
# each line is one label. the build embeds them with the same model as the
# posts and ships the vectors beside them; a taste is "about" whichever label
# its average sits nearest. broad and narrow labels both belong here: the
# nearest one wins, and a narrow label only wins when it really is closer.
# a label that is too narrow pulls neighbours in ("the rust programming
# language" took the go blog), so name a field rather than one thing in it.
#
# the sections are the shelves of feeds.opml, so a new shelf can be checked
# against the words the page has for it. the reader never sees a shelf name;
# the label is what gets printed. order does not matter to the ranker.
# lines starting with # are ignored.
